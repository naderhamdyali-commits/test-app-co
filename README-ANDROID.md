# تطبيق ExamPro للأندرويد

التطبيق نافذة ويب كاملة تفتح منصة الاختبارات الموجودة على جهاز الخادم (نفس الشبكة).
عند أول فتح يسأل عن عنوان الخادم (مثال: 192.168.1.5:8088) ويحفظه.

## الطريقة 1 — بناء APK مجانًا على GitHub (بدون تثبيت أي شيء)
1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع كل محتويات هذا المجلد إلى المستودع (Add file ← Upload files) مع المجلد المخفي `.github`.
3. افتح تبويب Actions ← "Build Android APK" ← انتظر 4-6 دقائق.
4. ادخل على آخر تشغيل ← Artifacts ← نزّل ExamPro-APK ← فك الضغط ستجد ملف app-debug.apk.
5. انقله إلى الهاتف وافتحه (اسمح بالتثبيت من مصدر غير معروف).

## الطريقة 2 — Android Studio
افتح المجلد في Android Studio ← Build ← Build APK(s).
